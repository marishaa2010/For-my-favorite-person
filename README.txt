LOVE WEBSITE — GITHUB PAGES

1. Create a GitHub repository.
2. Upload the entire 'assets' folder and 'index.html' into the repository root.
3. Make sure the file names stay exactly:
   assets/title.jpg
   assets/scene2.jpg
   assets/card.png
   assets/bus.png
   assets/cats.png
   assets/graves.jpg
   assets/graves.png
   assets/letter-closed.jpg
   assets/letter-open.png
   assets/song.mp4
4. In GitHub: Settings -> Pages -> Deploy from a branch -> choose the main branch and / (root).
5. Open the GitHub Pages URL.

INTERACTIONS
- Title page: tap OPEN IT.
- Loading screen: 5 seconds, crimson/pink pixel-style progress bar.
- Page 2: tap the play button on the red music card. The uploaded song starts and the animation starts together.
- 0–4 sec: lyric card and bus move toward the cats.
- 4 sec: cartoon BOOM/impact.
- 4–8 sec: impact sequence continues and bus moves off.
- 9 sec: graves emerge.
- 9–12 sec: graves remain.
- 12 sec: NEXT appears at bottom-right.
- NEXT -> closed letter.
- Tap the envelope -> open letter.

NOTE ABOUT THE SONG
The uploaded MP4 is about 13.84 seconds long. The visual scene is intentionally synchronized to 12 seconds and the code pauses the song at 12 seconds so the NEXT button appears at the end of the 12-second scene.
